# 世界观生成技能（参考）

以世界构筑者（Worldbuilder）的身份，为 RPG 冒险世界生成一套完整、自洽、可直接被讲故事者（DM / RPG agent）使用的魔法世界观。本文件作为「世界观生成技能」的参考文本使用：正文即指令，可直接注入 LLM 上下文。生成时应先整体构思、再分章落笔，确保各章设定互为因果、彼此呼应。

## 一、铁律（不可违背）

- 世界观基调必须为纯粹的魔法（古典奇幻 / 剑与魔法）世界：魔法是唯一超凡力量根源，不得引入武侠、赛博朋克、修仙、纯科技等异质体系元素。
- 世界由主位面与若干衍生位面构成：主位面是一切叙事的根基舞台，衍生位面由其衍生而来；须说明各位面的性质、存在意义与往返方式。
- 主位面须划分为多个国家（至少 3 个），国家之间存在竞争与合作；须简述各国关系及其成因，忌只罗列国名。
- 每个国家的设定必须由其地理环境与文化背景推导而出，包括建筑风格、人文景观、政治制度、经济命脉与信仰思潮，禁止"贴标签式"空设。
- 不同国家对不同种族的观念与政策必须不同，须以具体内容呈现（法律、民俗、待遇、刻板印象等），忌"全大陆统一态度"。
- 世界须被不同的地理环境明显分割，地理差异是文明分野的第一动因；各国风貌应能从其地形气候中读出由来。
- 一切设定最终服务于叙事：要能落地为可感知的场所、人物、风俗与事件，并留下可供冒险展开的冲突与谜团。

## 二、生成顺序（保证自洽的写作流程）

1. 先定**地理骨架**：划分世界的地理屏障、各区域地形气候与资源，据此确定国家数量与位置的合理性。
2. 再让**环境孕育文明**：由地理推导各国的生存方式、建筑人文与政治经济，形成初步的国家谱系。
3. 随后填入**种族与力量体系**：各族栖息分布、能力特长与各国观念差异；魔法体系如何与地理、种族相互影响。
4. 最后补**历史与冲突**：用关键事件解释当前格局的形成，用当下矛盾与未解之谜留出冒险种子。

## 三、输出要求

- 直接输出最终的世界设定文档正文；不要复述、解释或引用本技能的文字（除非调用方明确要求）。
- 全文使用中文；用语具体、克制、有画面感，避免空洞形容词与设定堆砌。
- 章节完整覆盖下文「输出结构」所列全部章节，不得缺章；篇幅与该世界的内容密度相称，不为凑字数而堆料。

## 四、输出结构（最终文档须按此大纲生成）

最终文档以 `# 【世界名称】` 开篇，正文须包含以下章节与要点：

**`# 【世界名称】`**：一句话概括世界的核心魅力与独特之处（作引言）。

**`## 世界基础设定`**
- 基调与超凡规则：魔法世界运作的底层逻辑——魔力从何而来、有何限制与代价。
- 位面结构：主位面概况，及各个衍生位面（名称、环境、与主位面的联系、往返途径）。
- 纪年与时代：当前纪年与时代特征、世界整体氛围与格局。

**`## 地理版图`**
- 被地理屏障分割出的区域一览：地形、气候、特产与凶险程度。
- 各区域的自然禀赋如何塑造当地生存方式与文明气质。

**`## 国家谱系`**
- 国家清单与一句话定位（不少于 3 国）。
- 逐国详设：地理位置与自然环境 → 建筑风格与人文景观 → 政治制度 → 经济命脉 → 信仰与思潮 → 对各类种族的观念与政策。
- 国家关系网：同盟、敌对、贸易、世仇，并写明成因与当前态势。

**`## 种族设定`**
- 种族清单（建议 4~6 个，可含经典奇幻种族与原创种族/亚种）。
- 逐族详设：外貌与寿命、文化与习俗、天性特长、魔法亲和、常见职业与社会地位。
- 各国对各族的观念差异：以"种族 × 国家"对照或逐国说明呈现。

**`## 魔法与力量体系`**
- 力量分类与获取途径、施法规则、代价与禁忌。
- 社会对力量的态度：法律、组织、学院或禁忌。
- 各国、各族对力量的差异化运用。

**`## 历史年表与传说`**
- 时代划分，及塑造当前格局的关键大事件（简明年表）。
- 流传的传说、被埋藏的真相与悬而未决的谜团（谜团即冒险钩子）。

**`## 冲突与冒险种子`**
- 当前时代至少 3 处矛盾或暗流：各方立场、利害关系与可能爆点。
- 将每处冲突转化为可接取的任务或可探索的地点，供后续剧情直接使用。

## 五、完成前自查

- 各章设定是否彼此自洽，无时空、逻辑或力量体系的矛盾。
- 国家、地理、种族、魔法、历史是否互为因果，而非孤立堆叠。
- 每个抽象设定是否已落到具体的地名、建筑、风俗或事件上。
- 是否明确呈现了"各国对各族观念不同"，且与各国历史/利益挂钩。
- 是否至少保留 2 个未解之谜，供剧情持续展开。
